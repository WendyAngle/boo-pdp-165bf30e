# 触达会话标签 / 分类弹窗统一方案

## 调整范围
- 仅将触达会话右上角标签按钮打开的小弹窗，替换为任务详情「目标明细」正在使用的「设置标签 / 分类」弹窗。
- 分类与标签仍是同一体系，不拆分为两个编辑项，不增加预置选项。

## 弹窗与关联数据
- 支持下拉多选系统已有标签、手动添加新标签、追加和覆盖，交互与目标明细完全一致。
- 打开时回显该会话关联目标已有的设置；保存到同一个目标标签记录，使任务详情、触达目标页和相关会话同步展示。
- 已有会话演示标签继续保留展示，并继续作为共享弹窗的可选标签；本次不迁移或清空历史会话标签。
- 不调整会话筛选、星标、消息发送及其他操作。

## 常显提示文案
- 保留「已选择 X 个目标：名称」的目标信息。
- 三处弹窗统一将「标签 / 分类跟随目标本身，会在触达会话列表同步展示。」改为：「修改后，该目标在任务详情、触达目标和相关会话中的标签 / 分类同步更新。」
- 文案说明修改影响范围，不在触达会话中重复强调当前列表，也不增加额外提示区。

## 技术实现
- 会话入口直接复用 `TargetTagDialog`，以现有 `targetTagKey(thread)` 关联目标，移除原来仅向会话追加标签的小弹窗逻辑。

## 验证
- 从会话打开弹窗，确认与目标明细一致。
- 验证选择已有标签、手动添加、追加与覆盖，以及保存后重新打开回显和关联目标同步展示。

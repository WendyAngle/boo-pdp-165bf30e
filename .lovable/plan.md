# 触达会话已有标签回显修正

## 问题原因
会话列表展示的是「目标标签 / 分类 + 历史会话标签」，但弹窗目前只读取目标标签。截图中的「真实度样本」等历史会话标签因此没有显示，导致列表与弹窗看起来不一致。

## 修正方案
- 在共用弹窗增加「已设置标签 / 分类」展示区，位于客户标签选择项上方，展示所选目标已有的标签 / 分类。
- 会话入口同时展示该会话已有的历史标签，合并去重，沿用刚统一的浅底、细边框样式。
- 目标标签继续在下方多选项中回显并可移除；历史会话标签仅作为已有信息展示，不自动复制进目标标签，也不被追加 / 覆盖操作清空。
- 历史会话标签仍可从已有标签选项中主动选择后设置到目标，保持现有操作规则。

## 范围与验收
- 仅调整共用弹窗的已有标签展示及会话入口传入的信息，不修改会话筛选、意向评分、数据存储规则或其他页面布局。
- 验证附件中的 Euro Bulk Distributor 会话：打开弹窗即可看见列表已有标签；关闭重开、添加目标标签、保存后跨页面同步均保持正常。
